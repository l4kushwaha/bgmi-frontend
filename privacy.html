1. Data We Collect

1.1 Account Information

When you register: email address, chosen username, hashed password (bcrypt), and 2FA secret (if enabled).

1.2 Profile Information

Optional: display name, avatar, bio, city. For KYC verification: government ID documents (Aadhaar, PAN, etc.) - encrypted at rest.

1.3 Transaction Data

Order details, listing information, UPI IDs (seller & buyer), payment amounts, UTR numbers, timestamps, escrow status.

1.4 Communications

All chat messages, voice recordings, file attachments exchanged via platform chat. We do not read private chats unless a dispute is opened.

1.5 Technical & Usage Data

IP address, device fingerprint, browser user agent, operating system, referral source, page views, feature interactions, error logs.

3. Data Sharing

3.1 With Other Users

Visible on your public profile: username, display name, avatar, bio, city, join date, ratings, badges. Hidden: email, UPI, KYC docs, IP, password.

3.2 With Service Providers

  • Cloudflare Workers: Hosting & API (processes data on our behalf)
  • Email Service: Sends OTPs, notifications (only email & name)
  • UPI Verification: Validates UPI IDs (only UPI string)

All processors sign Data Processing Agreements. No data sold to third parties.

3.3 Legal Requests

We may disclose data if required by law, court order, or to protect rights/safety. We'll notify you unless legally prohibited.

4. Data Storage & Security

4.1 Storage Location

All data stored on Cloudflare Workers KV / D1 (India/Asia regions). Encrypted at rest (AES-256) and in transit (TLS 1.3).

4.2 Security Measures

  • Passwords: bcrypt (cost factor 12)
  • JWT tokens: HS256, 15min access / 7day refresh
  • 2FA: TOTP (RFC 6238)
  • KYC docs: Encrypted, access-logged, auto-deleted after verification
  • Rate limiting, WAF, DDoS protection via Cloudflare

4.3 Access Control

Only authorized admins access user data for dispute resolution. All access logged. No third-party analytics (Google Analytics, etc.).

5. Your Rights (Under Indian IT Act / GDPR Principles)

  • Access: Request copy of your data via email
  • Rectification: Update profile info anytime in settings
  • Erasure: Delete account in Profile → Settings (irreversible)
  • Portability: Export your data (CSV/JSON) from Profile
  • Restriction: Request processing pause during disputes
  • Objection: Opt out of analytics (email us)
  • Withdraw Consent: For KYC, marketing (if any)

Email lkushwaha6161@gmail.com to exercise rights. Response within 30 days.

6. Cookies & Tracking

We use zero tracking cookies. No Google Analytics, Meta Pixel, or third-party trackers.

6.1 Essential Cookies (LocalStorage)

  • token, refresh_token - Authentication (HttpOnly equivalent via secure storage)
  • user - Cached profile for UI
  • bgmi-market-theme - Dark/light preference
  • bgmi-visited - First-visit flag for login flow

6.2 Session Storage

Temporary UI state (open modals, form drafts). Cleared on tab close.

6.3 You Control It

Clear all data anytime: Browser settings → Site data → Delete. Or use "Delete Account" in Profile.
